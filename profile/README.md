# RE:Pepper
Reverse Engineering Super Mario 3D Land Project.  

> [!NOTE]
> The project is currently on hold. If you want to work on it, ask me (Moddimation) on the [3ds decomp discord](https://discord.gg/37mBTzvWsU).

> [!WARNING]
> The Goal of this project is to decompile and try to replicate the original code, not to get it working on another system or make it easier to pirate the game or access it for free. Even if a full decompilation is achieved, assets are required to get the code running on a real console. There is no way around buying the original game.

> [!IMPORTANT]
> This project accepts AI assisted decompilation, but NOT AI generated decompilation. It is okay if the code was checked, understood and fixed up by the decompiler.
